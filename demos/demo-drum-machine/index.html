Drum machine: program a pattern, let the machine play it

This is the machine the session describes: a 16-step drum machine in the TR-808 mould. Click the grid to place hits for six drum-machine voices, one row per voice, sixteen steps per bar. Press Start to enable sound, then Play: the box runs the pattern with mechanical timing, every hit exactly on its step, the same way every bar. Load the four-on-the-floor preset to hear the pulse behind I Feel Love and the motorik lineage, or the electro / 808 preset for the Planet Rock lineage.
